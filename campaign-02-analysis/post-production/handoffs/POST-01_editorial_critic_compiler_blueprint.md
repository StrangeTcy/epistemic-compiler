# Editorial critic blueprint (Mercury POST-01)

1. Thesis: keep dissociation thesis (belief right, decision fragile).
2. Opening: start with the controlled probe result (0/36 belief flips vs 5/36 terminal flips).
3. Structure: probe -> broader exact-match -> proxy interventions -> implications -> caveats.
4. Precision: label "decision layer" as an interpretation, not a measured mechanism; use "decision/selection behavior".
5. Examples: include one concrete T1 flip (cell 4 facts, prior 1/3, seed 0: posterior 3/11 both orders; terminal answer changes correct->wrong).
6. Boundaries: state single model, 36 pairs, no CI, difficulty confounding.
7. Voice: technical, self-critical, no hype.
8. Reject: averaging prose; choose evidence over elegance.
